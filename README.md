# React Course 2026

A 50-hour React SPA course covering web fundamentals, React basics, routing, state management, styling, deployment, and AI-assisted development. Students build and deploy a capstone project to GitHub Pages by the end.

## Table of Contents

| # | Session | Topic |
|---|---------|-------|
| 01 | [How the web works](2026/01-how-the-web-works/) | Client-server model, HTTP, browser rendering pipeline, dev tools, npm, and module systems. |
| 02 | [Modern JS for React](2026/02-modern-js-for-react/) | Destructuring, spread/rest, arrow functions, array methods, promises, async/await, and fetch. |
| 03 | [Vanilla JS fetch mini-app](2026/03-vanilla-js-fetch-mini-app/) | Fetch a public API and render to the DOM by hand, no React yet. |
| 04 | [React intro, JSX, props](2026/04-react-intro-jsx-props/) | Vite setup, JSX, function components, props, lists and keys. |
| 05 | [State, events, styling](2026/05-state-events-styling/) | useState, event handling, conditional rendering, CSS Modules intro. |
| 06 | [Practice: component-driven UI](2026/06-practice-component-driven-ui/) | Throwaway todo-list practice app to solidify state and props. |
| 07 | [useEffect, data fetching](2026/07-useeffect-data-fetching/) | useEffect, hooks vs lifecycle thinking, loading/error/empty states. |
| 08 | [Forms, custom hooks](2026/08-forms-custom-hooks/) | Controlled forms, validation, lifting state up, first custom hook. |
| 09 | [Practice: capstone idea](2026/09-practice-capstone-idea/) | Apply fetch/useEffect to capstone idea; capstone topic chosen this week. |
| 10 | [React Router / SPA nav](2026/10-react-router-spa-nav/) | Routes, Link/NavLink, nested routes, dynamic params, useNavigate. |
| 11 | [Project architecture](2026/11-project-architecture/) | Folder structure, presentational vs container components, env variables, Vite base config. |
| 12 | [Build routing into capstone](2026/12-build-routing-into-capstone/) | Add routing and navigation to capstone project. |
| 13 | [Context API / useReducer](2026/13-context-api-usereducer/) | Context API, useReducer, when to lift state vs reach for Context. |
| 14 | [API layer patterns](2026/14-api-layer-patterns/) | Dedicated services/api layer, error handling patterns instead of scattered fetch. |
| 15 | [Build state/data layer into capstone](2026/15-build-state-data-layer-capstone/) | Integrate global state and data layer into capstone. |
| 16 | [Styling & layout](2026/16-styling-layout/) | Styling strategy, responsive layout with flexbox/grid, design consistency. |
| 17 | [A11y + performance](2026/17-a11y-performance/) | Accessibility basics, React.memo/useMemo/useCallback, React Compiler, lazy loading. |
| 18 | [Style/polish capstone](2026/18-style-polish-capstone/) | Style and polish pass on capstone project. |
| 19 | [Git workflow + GH Pages deploy](2026/19-git-workflow-gh-pages-deploy/) | Git/GitHub workflow, GitHub Pages deployment, SPA routing gotcha. |
| 20 | [opencode: setup & AI-assisted dev](2026/20-opencode-setup-ai-assisted-dev/) | Install opencode, TUI basics, workflow for AI-assisted development and diff review. |
| 21 | [Deploy capstone with opencode](2026/21-deploy-capstone-with-opencode/) | Deploy capstone to GH Pages, using opencode for debugging and deploy scripting. |
| 22 | [Capstone review + debugging clinic](2026/22-capstone-review-debugging-clinic/) | Group debugging: stale closures with useEffectEvent, missing deps, key warnings. |
| 23 | [Testing basics + error handling](2026/23-testing-basics-error-handling/) | React Testing Library basics, 2-3 meaningful tests, error boundaries. |
| 24 | [Free build / office hours](2026/24-free-build-office-hours/) | Buffer session for anything that ran over, open build time. |
| 25 | [Demo Day](2026/25-demo-day/) | Live demos, quick code review, and where to go next. |
